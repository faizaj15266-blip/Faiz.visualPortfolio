# Faiz — Personal Portfolio

Website statis responsif dengan gradasi biru-teal bergerak, palet warna dari referensi, dan animasi reveal yang ringan.

## Cara preview
Buka `index.html` di browser. Untuk pengalaman terbaik, gunakan browser modern.

## Cara publish ke GitHub Pages
1. Masuk ke GitHub dan buat repository baru, misalnya `faiz-portfolio`.
2. Upload semua isi folder ini (pastikan `index.html` ada di root repository).
3. Buka **Settings → Pages**.
4. Di **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/(root)`, lalu klik **Save**.
6. Tunggu GitHub Pages selesai deploy; URL akan tampil di halaman Pages.

## Personalisasi sebelum publish
- Ganti `Faiz` / `FAIZ` dan deskripsi profil di `index.html`.
- Ganti email `https://api.whatsapp.com/send?phone=6283831984805` dengan email atau kontakmu.
- Edit judul/deskripsi kartu karya di bagian `Selected Work`.
- Ganti logo pada `assets/logo.png` jika ingin memakai file logo transparan yang lebih bersih.

Website ini belum dipublikasikan ke akun GitHub mana pun; publikasi memerlukan akses akun pemilik repository.
